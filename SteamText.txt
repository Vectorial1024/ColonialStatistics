[h1]Mod Description[/h1]
RimWorld 1.6 performance improvements have enabled mega colonies (e.g. 20+ pawns).
With this, extra statistics is printed to let us better understand how well the colony is doing.

Find the statistics at Main Tab -> History -> Statistics.

Check the GitHub README for a list of printed statistics.
Alternatively, the in-game text box already prints you the statistics.

[h1]Frequently-Asked Questions[/h1]
When calculating "per capita", we only count and divide by free colonists.
